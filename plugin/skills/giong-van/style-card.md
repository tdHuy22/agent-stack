# Style card: giọng văn của người dùng

> Trạng thái: **chưa điền.** Chạy skill `giong-van` ở chế độ `tao-style-card` với 5 bài bạn tự viết, càng khác loại càng tốt (đặt trong `samples/`). Mỗi mục cần 1–2 câu trích nguyên văn làm ví dụ.

| Mục | Đặc điểm | Ví dụ trích từ bài của bạn |
|---|---|---|
| Xưng hô | (mình / tôi / em; gọi người đọc là bạn / anh chị / không gọi) | |
| Độ dài câu | (thích câu ngắn, hay câu dài nhiều mệnh đề?) | |
| Mức trang trọng | (thân mật, trung tính, học thuật) | |
| Cách mở bài | (vào thẳng việc, kể chuyện, nêu câu hỏi) | |
| Cách kết | (đưa hành động, câu ngắn, không kết) | |
| Từ hay dùng | | |
| Từ không bao giờ dùng | | |
| Dấu câu | (gạch ngang, ngoặc đơn, dấu chấm phẩy...) | |
| Thuật ngữ tiếng Anh | (giữ nguyên, dịch, hay giữ kèm giải thích) | |
