# Mẫu bài viết của bạn

Đặt vào đây 5 bài bạn **tự viết** (`.md` hoặc `.txt`), càng khác loại càng tốt: blog, email dài, ghi chú, bài luận cũ. Thêm bài ngoài khoảng 5 bài ít khi giúp bắt chước giọng tốt hơn; đa dạng quan trọng hơn số lượng.

Skill `giong-van` dùng các bài này để điền `style-card.md`. Script `tells.py` dùng chúng để đánh dấu những từ và cách xưng hô bạn hiếm khi dùng; cần tổng cộng ít nhất 500 từ.

Các file mẫu không được đưa vào git (xem `.gitignore`), vì có thể chứa thông tin riêng.
