# Threat model

Mỗi mục do skill `mo-hinh-de-doa` ghi cho một chức năng. `chot-viec` đưa các mục của chức năng đang chốt cho reviewer kiểm từng chốt chặn.

## 2026-10-09 · GĐ19: cài plugin bảo mật bên thứ ba ghim commit (vendor-plugin)
Luồng: `install.sh` (bạn duyệt) đọc `vetted.lock` và `catalog.json`, chép `.vet-cache/<repo>@<sha>/<thư mục con>` vào `vendor/plugins/<tên>`, thêm `vendor/` làm marketplace `agent-stack-vendor-local`, rồi `claude plugin install <tên>@agent-stack-vendor-local --scope user`.
