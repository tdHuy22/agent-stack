# saoluu.py

Trong bối cảnh dữ liệu ngày càng quan trọng, saoluu.py là giải pháp toàn diện giúp bạn bắt đầu hành trình bảo vệ dữ liệu một cách hiệu quả.

## Yêu cầu
Python 3.

## Cách dùng
```
python3 saoluu.py NGUON DICH --giu 5 --dry-run --keep-all
```

## Tùy chọn
- `--giu`: giữ 5 bản gần nhất.
- `--dry-run`: chạy thử.
- `--keep-all`: giữ tất cả.

Tóm lại, công cụ này không chỉ đơn giản mà còn mạnh mẽ.
